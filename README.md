## 如何部署到 GitHub Pages
1. 在 GitHub 新建 repo: taroko-rebirth-journey
2. 上傳整個資料夾內容
3. 到 Settings > Pages > Source: Deploy from branch > main / root
4. 網站會在 https://你的帳號.github.io/taroko-rebirth-journey/ 上線
